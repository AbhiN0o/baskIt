# Baskit

A two-sided artisan marketplace (buyers and sellers) built with React, Node.js, Express, MongoDB and the Gemini API.

- `frontend/` is the React + Vite app (deploys to Vercel)
- `backend/` is the Express API (deploys to Render)

See **[DEPLOY.md](./DEPLOY.md)** for step-by-step deployment and local setup.
